## 📋 What This Repo Is About

This repository is dedicated to everything involving **weather tracking and sensors**. It contains all the code, configurations, and documentation needed to read climate metrics from the physical world and process them.

### Sensors:
*   **Where:** The sensores are located in Nitra and about.
*   **Access:** Here you can get to a page where you can access all the info.
*   **Data Collection:**Also accessable here.

---

## 🛠️ How It Works

1. **The Sensors:** Physical sensor hardware captures the surrounding environment's data.
2. **The Code:** The scripts in this repository interface with those sensors to read the raw data.
3. **The Output:** The weather metrics are processed, structured, and formatted for viewing.
